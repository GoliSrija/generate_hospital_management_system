# Generate Hospital Management System

Generated by the AI Software Development Team.

- `frontend/index.html`: redirects to Login.
- `frontend/home.html`: generated landing page.
- `frontend/login.html` and `frontend/register.html`: demo authentication pages.
- `frontend/dashboard.html`: dashboard with working client-side module navigation.
- `frontend/css/style.css`: generated CSS plus fallback styling.
- `frontend/js/app.js`: generated JavaScript plus demo navigation.

Run the frontend locally from its directory using `python -m http.server 8000`,
then open `http://localhost:8000`.

IMPORTANT: authentication and CRUD screens are demos using browser storage.
Do not use them for real accounts or sensitive information. Connect secure Flask
authentication and database APIs before production deployment.
