##### AI Services:
- **POST /api/ai/generate**

##### Project Services:
- **GET /api/projects**

### Database
Database Name:
HospitalManagementSystem

Database Type:
- PostgreSQL

Main Tables:
- Patients
- Appointments
- MedicalRecords
- Prescriptions

Table Details:

**Patients**
- PatientID: SERIAL PRIMARY KEY
- FirstName: VARCHAR(50)
- LastName: VARCHAR(50)
- DateOfBirth: DATE
- Gender: CHAR(1)
- Address: TEXT
- PhoneNumber: VARCHAR(15)
- Email: VARCHAR(100)
- InsuranceNumber: VARCHAR(20)
- InsuranceProvider: VARCHAR(100)

Primary Key:
- PatientID

Foreign Keys:
- None

Relationships:
- One-to-Many relationship with Appointments (one patient can have multiple appointments)
- One-to-Many relationship with MedicalRecords (one patient can have multiple medical records)

Indexes:
- Index on FirstName, LastName for quick patient search

Constraints:
- NOT NULL for FirstName, LastName, DateOfBirth, Gender, Address, PhoneNumber, Email, InsuranceNumber, InsuranceProvider
- UNIQUE for Email, InsuranceNumber

**Appointments**
- AppointmentID: SERIAL PRIMARY KEY
- PatientID: INTEGER REFERENCES Patients(PatientID)
- DoctorID: INTEGER REFERENCES Doctors(DoctorID)
- AppointmentDate: TIMESTAMP
- AppointmentTime: TIME
- Status: VARCHAR(20) CHECK(Status IN ('Pending', 'Confirmed', 'Cancelled'))

Primary Key:
- AppointmentID

Foreign Keys:
- PatientID references Patients(PatientID)
- DoctorID references Doctors(DoctorID)

Relationships:
- One-to-Many relationship with Appointments (one doctor can have multiple appointments)

Indexes:
- Index on PatientID, DoctorID for quick appointment retrieval

Constraints:
- NOT NULL for PatientID, DoctorID, AppointmentDate, AppointmentTime, Status
- FOREIGN KEY constraints for PatientID and DoctorID

**MedicalRecords**
- RecordID: SERIAL PRIMARY KEY
- PatientID: INTEGER REFERENCES Patients(PatientID)
- RecordDate: DATE
- RecordText: TEXT

Primary Key:
- RecordID

Foreign Keys:
- PatientID references Patients(PatientID)

Relationships:
- One-to-Many relationship with MedicalRecords (one patient can have multiple medical records)

Indexes:
- Index on PatientID for quick record retrieval

Constraints:
- NOT NULL for PatientID, RecordDate, RecordText
- FOREIGN KEY constraint for PatientID

## Running the frontend locally

Open `frontend/index.html` in a browser or run a static server from
the `frontend` directory:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

Note: generated CRUD screens use browser localStorage as a demo.
They are not connected to a real database unless backend integration
is implemented separately.
