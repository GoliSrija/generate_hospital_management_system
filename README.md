# Generate Hospital Management System

Generated by the AI Software Development Team.

- `frontend/index.html`: redirects to Login.
- `frontend/home.html`: generated AI homepage.
- `frontend/login.html` and `frontend/register.html`: demo authentication pages.
- `frontend/dashboard.html`: dashboard modules chosen from the original project prompt.
- `frontend/css/style.css`: AI-generated CSS plus fallback styles.
- `frontend/js/app.js`: AI-generated JavaScript plus demo navigation and CRUD interactions.
- `backend/app.py`: basic Flask health-check API.

Run the frontend locally from the `frontend` directory using `python -m http.server 8000`,
then open `http://localhost:8000`.

IMPORTANT: authentication and CRUD screens are demos using browser storage.
Do not use them for real accounts or sensitive information. Connect secure Flask
authentication and database APIs before production deployment.
